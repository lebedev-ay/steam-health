# Черновик фактов для журнала решений: LLM-разметка отзывов

Факты и цифры под будущие записи `docs/decisions.md`. Формулировки выводов - за автором журнала. Подробности - в [exploration.md](exploration.md).

## Провайдер и модель

- Провайдер OpenRouter, модель разметки `qwen/qwen3.8-flash`.
- Разметка: размышления выключены, `temperature` 0.
- Первый вызов: размышления - 88 из 92 выходных токенов; без них тот же ответ в 3.5 раза дешевле.
- Проектирование справочника: `qwen3.8-max` с потолком размышлений.
- Первая попытка `qwen3.8-max` без потолка: 32 000 токенов, ответа нет, $0.20.
- Кэш провайдера: системный промпт кэшируется, 512 из 696 токенов; правка промпта сбрасывает кэш.

## Двухуровневая схема

- Уровень 1 - аспекты со знаком на каждый отзыв. Уровень 2 - агрегация в SQL.
- Вывод у точки перелома собирается из типа события, сдвига аспектов в окне и 2-3 цитат с `review_id`; модель пишет вывод по готовым цифрам.
- Онлайна в данных нет.

## Закрытый справочник после открытой разведки

- Открытая разведка: 3002 отзыва, 32 минуты, $0.15, покрытие 99.6%.
- 948 разных меток, 484 встретились один раз.
- 29 меток покрывают 50% упоминаний, 156 - 80%, 329 - 90%.
- При `temperature` 0 ответы различались, в основном формулировками меток, не знаками.
- Справочник v5: 12 категорий, 44 подаспекта.
- Тема вне справочника - `other` с меткой 1-3 слова.

## Вход разметки и идемпотентность

- Модели передаётся только текст отзыва: без голоса, часов в игре, названия игры.
- Ключ идемпотентности: текст + версия промпта + версия справочника + модель.
- В записи: `run_id`, модель, версия промпта, версия справочника.
- Номера 1..N вместо `recommendation_id`, обратное сопоставление по позиции.
- Проверка ответа в коде: JSON, номера ровно 1..N, id из справочника, знак, метка `other`.
- Упавшая пачка - поштучный повтор; 429 и 5xx - повтор с паузой 2/4/8 с.

## Размер пачки

- Замер на 30 отзывах: пачки 1/10/30 - 57/20/15 с.
- Цена почти одинаковая за счёт кэша.
- На пачке 30 - первое нарушение лимита тем.
- Выбрано 10.

## Знак ± и пропуск нейтрального

- Знаки: `+`, `-`, `±` (смешанный).
- Нейтральные упоминания не размечаются.
- Согласие разметчиков эталона по знаку - 94% (59/63 в выводе `evaluate.py`, без `overall_impression`).

## overall_impression только без конкретики

- `overall_impression` ставится, только если в отзыве нет конкретных причин.
- Основные цифры сравнения с эталоном - без `overall_impression`; с ним - в блоке «Тренды по категориям».

## Заморозка v5

- Версии справочника v1 -> v5; v1 - черновик сильной модели после ревью.
- Правки: разведены сложность врагов и баланс классов; разведены цена и монетизация; разведены три аспекта отношений с компанией; добавлены `solo_experience`, `localization`, `mod_support`, `game_lifecycle`; `world_design` сужен до физического мира.
- Эталон: 45 отзывов (английский и русский, по 15 на игру), два независимых разметчика: автор и Claude.
- Уточнение определений: согласие разметчиков эталона по подаспектам с 55% до 61%.
- Полная разметка v5: 3002 отзыва, 45 минут, $0.19; не прошли с первого раза 1.7%, после повтора 0.2% (7 отзывов).
- Основная причина отказов - id вне справочника: названия категорий вместо подаспектов, «игровой цикл» (`core_loop`, `gameplay loop`).
- v5 помечен `"status": "frozen"`.

## Тренды по категориям

- Согласие разметчиков эталона (автор - Claude): 61% по подаспектам, 72% по категориям.
- Модель (closed-v2, v5) с автором: 59% по подаспектам, 69% по категориям; с Claude: 76% и 80%. Без `overall_impression`.
- С `overall_impression`: автор - модель 57/64%, Claude - модель 74/78%, автор - Claude 64/73% (подаспекты/категории).
- `overall_impression` на 45 отзывах: модель 10, автор 34, Claude 21.
- Систематических перекосов на эталоне не выявлено.
- Согласие модели со вторым разметчиком-LLM частично отражает сходство машинного чтения.
