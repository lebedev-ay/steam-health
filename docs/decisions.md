# Журнал решений

## 001. Зерно fct_review — один отзыв

Дата: 2026-08-12

Контекст: отзыв в Steam мутабельный — автор правит текст,
переворачивает оценку, votes_up накапливается, разработчик
отвечает с задержкой.

Решение: accumulating snapshot, одна строка на отзыв,
колонки-вехи created_at / updated_at / dev_responded_at.

Альтернативы: SCD2 на факте — отвергнут как избыточный
для учебного объёма.

Последствия: история изменения мнения теряется,
фиксируется только текущее состояние.

## 002. Цена не попадает в dim_game

Дата: 2026-08-12

Контекст: price_overview меняется несколько раз в месяц
(распродажи). SCD2 по цене породил бы сотни версий строки
на игру — измерение перестало бы быть медленно меняющимся.
Дополнительно: цена не существует как единое значение —
она зависит от региона (параметр cc) и валюты.

Решение: цену как атрибут измерения не храним, историю цен
не собираем.

Альтернативы:
- отдельный факт fct_price_snapshot — отложено, дорого
  из-за региональной матрицы
- mini-dimension с диапазонами цен — избыточно для задачи

Отдельно зафиксировано: распродажа — confounder. Скидка
приводит новую аудиторию с другим профилем ожиданий,
доля негатива меняется без изменений в самой игре.
Риск ложной атрибуции всплеска патчу.

Митигация: флаг is_on_sale (из discount_percent на момент
замера) вместо полной истории цен. Дёшево, закрывает риск
неверной интерпретации.
