Переломы

Слова отзывов

Какие слова стали встречаться чаще, чем за 90 дней до периода, и о чём пишут вообще. Считается по отзывам на английском и русском, без модели. Щелчок по слову - отзывы с ним.

◇

Эта игра не размечается моделью, поэтому тем по справочнику, сводок месяца и разборов переломов у неё нет. Всё остальное - график, переломы, слова, аудитория, обновления и сами отзывы - считается без модели.

Темы по разметке модели

Критика по месяцам

Доля размеченных отзывов месяца, где тему ругают. Чем насыщеннее клетка, тем больше жалоб. Наведите на клетку - там точные числа.

Сводки по месяцам

Пишет модель по числам разметки - без текстов отзывов. Каждое число в сводке проверено кодом по данным.

Кто пишет

Доля положительных отзывов в разных группах игроков.

Реакция на обновления

Каждая новость игры, кроме маркетинга и блогов: доля позитива и число отзывов за неделю до и неделю после. Совпадение по времени - не доказательство причины. Щелчок по строке - отзывы недели после.
